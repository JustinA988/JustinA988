### Hi, I'm Justin

I build tools for running, inspecting, and evaluating language models, and a few local utilities.

| Project | What it is | Stack |
| --- | --- | --- |
| [ferrum](https://github.com/JustinA988/ferrum) | CPU Llama inference engine. Loads GGUF, tokenizes, and matches llama.cpp logits. | Rust, AVX2 |
| [mechinterp-lab](https://github.com/JustinA988/mechinterp-lab) | Local lab for logit lens, steering, circuit tracing, and SAE feature explanations. | Python, PyTorch, TransformerLens, Streamlit |
| [inspect-ai-safety-harness](https://github.com/JustinA988/inspect-ai-safety-harness) | Scores agent transcripts and rejects tool output that fails a declared schema. | Python, Pydantic |
| [local-context](https://github.com/JustinA988/local-context) | Claude plugin MCP server for local files, shell, SQLite, and scheduled tasks. | Python, MCP |
| [agentflow](https://github.com/JustinA988/agentflow) | Turns a GitHub issue or review into a pull request using Claude Code, Codex, or a local Ollama model. No API keys. | Python |
| [kv-cache-simulator](https://github.com/JustinA988/kv-cache-simulator) | Simulates paged KV-cache allocation, sliding-window eviction, and prefix sharing. | Python |
| [handctl](https://github.com/JustinA988/HandCTL) | Webcam hand gestures for the mouse, scrolling, media keys, and virtual desktops on Windows. | Python, MediaPipe |
| [tidy](https://github.com/JustinA988/tidy) | Finds duplicate files by content, sorts them with TOML rules, and can undo every move. | Python |
